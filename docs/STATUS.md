## Current state

- **Production AI is up on Vertex AI** (#2, deployed and verified 2026-10-16). Bills to Blaze.
  `gemini-3.6-flash` and `gemini-3.1-flash-lite` both verified on Vertex `global`; runtime SA `kova-run`
  has `roles/aiplatform.user`. The `GEMINI_API_KEY` secret mount remains for rollback (KOVA-034).
- **Cost guardrails:** billing budget alert is set (outside the repo). Cloud Run max instances capped at 3
  in KOVA-011.
- **Cloud Scheduler:** job `kova-monthly-letters` exists (daily 21:00 UTC, `europe-west1`) and calls
  `POST /api/cron/monthly-letters`. The route itself only runs on the last day of the month.
- **Premium plan** is server-owned (`users/{uid}.entitlement`, KOVA-010). Set by an admin
  (`PLAN_ADMIN_UIDS`) or by a RevenueCat-verified Google Play purchase (KOVA-077, `docs/BILLING.md`); purchases
  stay off until the Play/RevenueCat setup and the two secrets exist. Firestore rules are deployed **by hand** (`firebase.json`).
- PayPal: the real sandbox works locally (KOVA-020a): check-in reads it and the confirmed cancel happens in PayPal. Production still
  runs `PAYPAL_MODE=mock` until the deploy step (secret in Secret Manager + repo variables, KOVA-020 A7).
- **Android** (KOVA-050): Capacitor 8 project generated, `com.kovafinance.app`; debug APK builds with JDK 21.
  Not yet on Play; Google Sign-In needs `google-services.json` (follow-up). See [ANDROID.md](ANDROID.md).
- CI (typecheck, build, gitleaks, Docker) and deploy-on-merge to Cloud Run are in place.
- **Chat and expense storage (KOVA-062):** one Firestore doc per item at `users/{uid}/messages/{id}` and
  `users/{uid}/expenses/{id}` (`storageVersion: 2` on the user doc). Legacy users migrate on next login;
  their old `messages`/`expenses` arrays stay in the user doc as an unread backup (delete after 2026-11-12).
